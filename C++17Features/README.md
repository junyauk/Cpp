# C++17 Features — Solution

This solution contains multiple sample projects demonstrating C++17 language and library features. Each project lives in its own directory and includes a project-local `README.md` describing purpose, build steps and usage.

Repository layout (example)
- `ProjectA/` — Example project A
- `ProjectB/` — Example project B
- `third_party/` — Optional third-party libraries or submodules

Requirements
- OS: Windows 10/11
- IDE: Visual Studio 2022
- Compiler: MSVC (set to C++17)
- C++ language standard: ISO C++17

Quick build (Visual Studio 2022)
1. Open the solution or the project folder in Visual Studio 2022.  
2. Set the configuration to `Debug` or `Release`.  
3. For each project, verify C++ standard: Project Properties → __C/C++ → Language → C++ Language Standard__ → `ISO C++17`.  
4. Build the solution (Right-click solution → Build Solution).

Per-project README
- Each project directory should contain its own `README.md` with project-specific instructions (build, run, examples). A template is provided in the repository: `PROJECT_README_TEMPLATE.md`.

Testing
- Describe test frameworks and how to run tests in the project-level README.
